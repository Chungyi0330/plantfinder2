這個後台怎麼運作？

因為網站發布在 GitHub Pages（純靜態、沒有伺服器），這個後台不會自動把資料存到雲端，而是幫你在瀏覽器裡把新植物整理好，最後讓你一次「下載」需要的檔案，再手動上傳到 GitHub。流程如下：

  1. 在下方表單填寫植物資料、上傳圖片，按「加入清單」（可重複新增多筆）。
  2. 加入清單時圖片會自動下載一份，檔名已經對應好，直接把它放進 repo 的 images/ 資料夾。
  3. 全部新增完後，按「下載 plants-data.js」，用下載的檔案覆蓋 repo 裡原本的 plants-data.js。
  4. 把 images/ 裡新增的圖片與更新後的 plants-data.js 一起上傳、commit 到 GitHub，Pages 會自動更新網站。
